# profile-koi

Draws [Rijad's](https://github.com/RijadRajkic) koi every night with [git-koi](https://github.com/yalongwastaken/git-koi)
and puts it in a little pond that reacts to the day's activity (`pond.mjs`): one ripple per contribution yesterday,
more lily pads the more active the last 30 days were, and flowers while a streak lasts. Both images are kept in `koi/`;
his GitHub profile shows `koi/koi-pond.gif`. The workflow is in `.github/workflows/koi.yml`.
